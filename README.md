# ⚽ Next Football PWA

Next Football is a **Progressive Web Application (PWA)** built with **Next.js**.  
It delivers real-time football match updates, team standings, and push notifications — optimized for both web and mobile.

---

## 🚀 Features

- ✅ **Progressive Web App** (installable on mobile & desktop)
- 📶 **Offline support** (service worker + fallback pages)
- 🔔 **Push notifications** (goal alerts, match updates)
- 📊 **Live match data** (real-time updates)
- 📱 **Responsive design** (mobile-first, works across devices)
- 🕹️ **Standalone app mode** (launches like a native app)
- 🌐 **SEO ready** (meta tags, OpenGraph, sitemap)

---

## 📂 Tech Stack

- [Next.js](https://nextjs.org/) – React framework
- [Supabase](https://supabase.com/) – authentication, database, real-time
- [Web Push](https://developer.mozilla.org/en-US/docs/Web/API/Push_API) – notifications
- [TypeScript](https://www.typescriptlang.org/) – static typing
- [Tailwind CSS](https://tailwindcss.com/) – styling
- [PWA](https://web.dev/progressive-web-apps/) – offline support, manifest
